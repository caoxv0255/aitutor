3 · 场景运行

手动触发一次 run. 因为 Playwright 必须在 host 进程跑, 这里是说明卡 + 跳转链接到复跑命令.

本地复跑

cd ~/aitutor
node scripts/headed-tests/run.mjs

结果会写到 frontend/dev/runs/<timestamp>/, 刷新本页可见.

DSH 浏览器插件 (重启 GUI 后)

browser_navigate url: "http://localhost:3002"
browser_snapshot
browser_click selector: "button:has-text('登录')"

详见 dsh-playwright-browser README.

截图尺寸策略

  • 1280 × 800 viewport (PC 端)
  • fullPage: true (捕获整页滚动)
  • headed: false + WSLg wayland (WSL2 真弹窗)
