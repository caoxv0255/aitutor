## 二、任务详情

### W2: bge-large-zh 中文 embedding (50+80 min)

**根因**: nomic-embed-text (768 dim) 中文 + LaTeX 弱, 排名区分度差. schema v5 高考题 60% 文本含 LaTeX, 中文数学题 vector 难准确.

**方案**: 换 bge-large-zh-v1.5 (1024 dim, 中文 better)
- 拉模型: `ollama pull bge-large-zh-v1.5` (~1.3 GB)
- 改 schema: `vector(768)` → `vector(1024)` (migration 006)
- 改 embedding.js: provider 加 bge 配置
- 改 ingestion: 用新 model 重 embed
- 改 ingest script: 默认 model

**收益**:
- 中文 math sim 提升 (期望 +20-30% recall)
- 跨学科 ranking 更准 (避免 math/化学 vector 跟其它学科乱跳)
- RAG 端点 4 端点不用改 (dim 是后端细节)

**风险**:
- 50 min 改 + 80 min 重 ingest (50k 题) = 2.2 hour
- 期间前端 demo 不可用 (bge 没拉/重跑中)
- 跟当前 ingest_v2 (nomic) 冲突, 必须等 ingest_v2 完

### W4: HNSW 索引切换 (30 min)

**根因**: pgvector ivfflat 索引 (lists=100) 在 10K-100K 数据时 recall ~85%. 改 HNSW (Hierarchical Navigable Small World) recall ~98%, 速度稍慢但 < 100ms.

**方案**:
- 改 migration 005: `CREATE INDEX USING hnsw (embedding vector_cosine_ops) WITH (m = 16, ef_construction = 64)`
- Drop 旧 ivfflat
- Test 100 query 测 recall

**收益**:
- 50k+ 数据下 HNSW 精度 +13% (vs ivfflat)
- 100ms 响应保持
- 不需要 re-ingest

**风险**:
- 索引 build 时间: 50k 题 ~30s (一次)
- 期间 query 慢 (建索引)
- 必须等 ingest_v2 完 (dim 定了)

### W6: AGE+pgvector 自定义镜像 (15+60 min)

**根因**: 之前 P3 选官方 pgvector 镜像 (无 AGE), 知识图谱 (方案 A) 没用. 知识图谱 = 用户行为 + 题目关系, 重要但非关键.

**方案**:
- build Dockerfile.postgres (P3 已写, 在 /home/cx/智启复习/Dockerfile.postgres)
  - 编译 pgvector v0.5.1 + Apache AGE
  - 镜像名: zhiqui-postgres:15-age-pgvector
- 重启 zhiqui-postgres 容器 (用新镜像)
- migration 加 AGE extension + KnowledgePoint 表
- 评估: 用不用 (知识图谱对当前 demo 价值小)

**收益**:
- 知识图谱接入 (方案 A 启用)
- 长期可做"题目关系图" (相似题, 知识点拓扑)
- 短期: W6 可能放弃 (工作量 vs 价值低)

**风险**:
- 15 min build 编译 (如果 docker daemon 慢, 可能 30 min)
- 60 min 迁移 + init (空表)
- 可能跟 v0.6 P3 pgvector 容器冲突 (docker rm + run)

### W7: difficulty / KP 字段反查 (半天)

**根因**: 
- rag_questions.difficulty 字段空 (schema v5 没这字段)
- knowledge_point_id 字段空 (vendor 没标 KP)
- 现有: `quality.confidence` (0.0-1.0) 可推 difficulty (1-5)
- 知识章节: 需要 vendor 重提取, schema v5 缺

**方案 (本会话)**:
- ingest script: difficulty = `int(quality.confidence * 5) if quality else None`
  - 0.0-0.2 → 1 (简单)
  - 0.2-0.4 → 2
  - 0.4-0.6 → 3
  - 0.6-0.8 → 4
  - 0.8-1.0 → 5 (难)
- KP: 留 None, v0.7.x vendor 字段加上后填

**收益**:
- metadata 完整, 可按难度筛选
- "导数难题" "导数简单题" 区分
- 跟 KP map 集成 (W3) 准备

**风险**:
- 简单公式, 不破现有
- 跟 ingest 一起跑 (~3-5 min, 改 formula)
