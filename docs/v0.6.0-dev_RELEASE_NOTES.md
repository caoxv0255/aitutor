## 🔧 关键技术决策

### E1 (DashScope 公共 key) ✗
用户没公共 key, 给的 Maas workspace key 锁 workspace.

### E2 (Maas + 本地混合) ✗
Maas workspace 权限只允许 qwen3.7-max/plus chat, embedding 全 403 (测了 8 model + 2 endpoint).

### A1 (build 自定义 AGE+pgvector 镜像) — 留 v0.7
15-20 min build, 跟 pgvector ingest 强耦合, 不阻塞 P3.

### A2 (修 LiteLLM + 本地) ✗
3 个变量同时解决 (LiteLLM unhealthy + Ollama + dim), 调试空间大, 不符合 "风险最低" 原则.

### **B + P3 (官方 pgvector 镜像 + 本地 Ollama)** ✓
- 5 min 拉 pgvector 官方镜像 (mirror 加 docker daemon.json)
- 137MB Ollama nomic-embed-text 装好
- schema 改 1536 → 768 (单点改动)
- embedding.js 加 ollama provider (3 选 1)

### 决策核心: "一次解决 1 个变量"
参考 Hermes A2 失败教训, 用户建议**先验证数据库链路 → 再决定本地 embedding**. 避免一次解决 3 个变量, 调试空间大.
