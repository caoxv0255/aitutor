## 架构：双投影

`read_paras(path, table_aware=True)` 返回两个**逐段对齐**的投影：

| 投影 | 内容 | 用途 |
|------|------|------|
| `paras_seg`（展开） | **逐段 == base**（直接复用 `body.iter(W+'p')`） | 切分、选项、答案回填、碎片/非题目判定 |
| `paras`（干净） | 在 `paras_seg` 基础上，把每张 data_table 的**每个**单元格段落替换为 `⟦TABLE:n⟧`；option_layout 保留原文 | 组装 stem 显示文本 |

**核心不变量：`paras_seg` 必须与 base 段落列表逐段一致。**
只要它成立，切分/选项/答案就必然复现 base，不再依赖 `_walk_body` 去逐一复刻 base 的段落数。

`split_questions(paras, stem_paras)`：路由判定一律用 `paras`（展开），
仅 stem 显示文本取 `stem_paras`（干净）。同时另存 `cur['stem_seg']`（展开题干）
供 finalize 的**碎片/非题目判定**使用——这些判定必须复现 base，否则表题会被误杀或误留。

## 关键设计点（踩坑换来的）

1. **paras_seg 直接 = `body.iter(w:p)`**，不用 `tbl.iter(w:p)` 手工复刻。
   旧 `_walk_body` 对含文本框嵌套的复杂表（实测 2009 广东生物 #34 流程图）只数到 1 段，
   而 base 数到 7 段 → 段落错位，表内选项/答案与 base 不一致（该卷 base 154 / ta 132）。
2. **索引守恒**：每张 data_table 占 k 段就保留 k 段（每个单元格都放占位符），不能折叠，
   否则 `mask_regions` / `candidate_layouts` 的 region 索引整体前移。
   单题表内的连续占位符由 `_append_stem` 去重成一个。
3. **表型分类**：首列 ≥50% 匹配 `OPT_LEAD`（`^[A-D][．.、)]`）→ option_layout（保留原文，
   换占位符等于删选项）；否则 data_table（换占位符）。
4. **碎片/非题目判定用展开 stem**（`stem_seg`）：`is_fragment` / `is_boilerplate` 一律读
   `stem_seg`，复现 base。盲目「保所有含 ⟦TABLE:⟧ 的题」会留下 base 判为碎片的表细胞题（实测 3745）。
5. **去重键用展开 stem**（本报告新增修复，见下）：
   `assign_sections` 的同卷重复题去重，键必须取 `stem_seg`，不能用干净 stem。

## 修复历程（通过率 172 → 198 → 200 → 760）

| # | 现象 | 根因 | 修复 |
|---|------|------|------|
| 1 | 3805：表题 14→6 | 占位符被 `is_fragment` 误杀 | 判定改用展开 stem |
| 2 | 多题同表时干净 stem 为空 | 只在首格放占位符 | 每格都放（索引守恒），续行去重 |
| 3 | 占位符被截坏 `ABLE:2⟧` | 用展开文本的 QNUM 偏移切干净文本 | 在干净文本自身匹配 QNUM |
| 4 | 3745：ta 多出伪题 | 盲目保占位符 stem | 撤回护栏，判定一律用展开 stem |
| 5 | 3820：41→46 | `stem_seg` 在 boilerplate 判定前被 pop | pop 移到过滤之后 |
| 6 | 3728：复杂表段落数漂移 | `_walk_body` 与 base 枚举口径不一致 | `read_paras` 重写：paras_seg 直接 = base |
| 7 | **3856 答案 5→7、3917 options** | **去重键用干净 stem，占位符编号不同 → 漏去重** | **去重键改用 `stem_seg`** |

### 第 7 项详解（最后 2 卷，同一根因）

同一道题在**正文**与**卷末解析区**各出现一次（上海/浙江解析卷常见）。base 中两处题干
展开后文本相同 → `assign_sections` 判为重复、去重（保留第一条，即正文那条）。
治本下干净 stem 一处是 `⟦TABLE:1⟧`、另一处是 `⟦TABLE:3⟧`（两张同文本的表），
去重键不同 → **漏去重** → ta 多留一条带 `from_analysis` 答案的题（3856 有答案 5→7）。

两卷（3856 / 3917）经 `paras_seg` 逐段比对确认**首差 None**（展开投影完全一致），
分叉只发生在 `assign_sections` 的去重键上。修复：键取 `stem_seg or stem`，
并把 `stem_seg` 的清理从 `finalize` 移到 `assign_sections` **之后**。
base 下 `stem_seg == stem`（全量 0 违例）→ base 去重键不变。
