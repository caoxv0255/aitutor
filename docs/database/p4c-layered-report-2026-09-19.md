## 为什么是路线 A（不是整卷重抽取）

整卷「表感知重抽取」pilot 实测卷级下降（有答案 −3.7% / 可用题 −2.1%），归因证明
**表格段落同时是管线输入**：卷末答案表的证据（2.5% 的答案）与题号计数（影响 tail 候选
与布局择优）都依赖表内段落。见表 `p4c-decline-analysis-2026-09-19.md`。

路线 A 的关键洞察：**这两件事不需要同一份解析**。

| 通道 | 职责 | 表格怎么处理 |
|------|------|------|
| base（原样） | 切分、答案回填、统计 | 表内文本可见 → 答案表证据 / 题号计数不丢 |
| table-aware | 只生成 stem | data_table → `⟦TABLE:n⟧`；option_layout 保留原文 |

## 四道机械护栏（不猜，宁可不改）

两遍（`table_aware=False/True`）逐题对齐，任一不满足 → **整卷回退 base**：

1. **题号集合完全一致**（不多不少）—— 防切分漂移
2. **每题 options 键集合一致** —— 防选项被改
3. **段落数守恒**（`read_paras` base==ta）—— 占位符段落数 = 原表内段落数（k），
   否则 `mask_regions` / `candidate_layouts` 的 region 索引越界
4. **填空标记守恒**（新增）—— base stem 有 `_{2,}|＿{2,}|（\s{2,}）|…` 而 ta 没有 → 回退

护栏实测触发计数（全量）：题号不齐 162 / 选项不齐 64 / 索引不守恒 57 / 填空标记丢 8。
