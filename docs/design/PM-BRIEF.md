**判定链 (P0-1 修正)**: 学段 → 中考/高考 → (高考时) 省份 → 3+3 / 3+1+2

#### A.2.1 register.html — 1 步 (P0-7 修正: 只管账号凭证)

| 步骤 | 用户行为 | 系统响应 | 数据写入 |
|---|---|---|---|
| L2.1 注册凭证 | 方式选择 (手机号+验证码 / 微信 OAuth / 邮箱+密码 兜底) + 邀请码 (选) + 密码 | 创建 `users` 行 (匿名游客态可升级) | users.phone / users.wechat_openid / users.email, users.password_hash |
| → 跳转 onboarding.html | | | |

> **P0-4 修正**: 手机号为主, 微信次之, 邮箱保留兜底。游客试用 = 本地态可拍照 3 次/天, 注册时合并数据。

#### A.2.2 onboarding.html — 5 步 (稍后可跳过单步)

| 步骤 | 用户行为 | 系统响应 | 数据写入 |
|---|---|---|---|
| L3. 昵称 + 头像 | 显示名 + 默认/上传头像 | — | users.nickname, users.avatar_url |
| L4. 年级 | 小学 / 初中 / 高一 / 高二 / 高三 | **写入学段 → 自动判定 中考区 / 高考区** | users.grade, users.exam_type (auto) |
| L5. 省份 | 31 省份下拉 (高考时必填, 中考可跳) | **按 §F.8 映射表判定 3+3 / 3+1+2** | users.province, users.subject_strategy |
| L6. 选科 (高考) | 6 选 6 (3+3: 语数外 + 3 选科 / 3+1+2: 语数外 + 1 首选 + 2 再选) | 写入, 阻止提交超过 6 科 | users.subject_selection |
| L7. 首题引导 | 拍照第一道错题 (示例题) | AI 识别 + 入库 + 排名 #1 | wrong_questions + srs_schedule |
| L8. 跳转 | 完成首题 | 跳转 Practice Hub | — |

> **支持 "稍后再选 →"** (每个 step 都能跳, 走默认: 高中 3+3 物化生)

### A.3 第 2 时期 · 日常学习期

| 步骤 | 用户行为 | 系统响应 | 数据写入 |
|---|---|---|---|
| D1. 进入拍照 | 从底部 Tab 进入 PWA 拍照页 | 唤起相机 / 相册 | — |
| D2. 拍照 | 拍照一道错题 | AI 0.4s 识别 (Qwen-VL-Max + OCR) | vision_jobs |
| D3. 查看解析 | 题干 + 4 步解题 + AI 老师讲评 | 返回识别结果 | — |
| D4. 答错 | 用户的答案 ≠ 标准答案 | **自动入库** (默认开启, 仅"拍照搜题"来源) | wrong_questions 行 |
| D5. 看 3 道相似题 | 系统推荐 | 跳转错题本/相似题推荐 | — |
| D6. 看 9 学科星图 | 进入知识图谱 | 节点按熟练度着色 | mastery_score |

### A.4 第 3 时期 · 复习巩固期

| 步骤 | 用户行为 | 系统响应 | 算法 |
|---|---|---|---|
| R1. 收复习提醒 | push 通知: "今日 3 道到时" | 时间到了自动 push | SM2 调度 |
| R2. 进入复习 | 点击进入 | 弹出卡片 | srs_review_queue |
| R3. 答 1 题 | 输入答案 (可不输入, 直接评分) | 系统比对 | — |
| R4. 评分 0-5 | 用户选 0=完全不会, 5=完美回忆 | SM2 算下一间隔 | EF' = EF + (0.1 - (5-q)*(0.08 + (5-q)*0.02)) |
| R5. 熟练度更新 | q=5 → 间隔 +6d; q=0 → 重置为 1d | 更新 srs_review_log | mastery_score += 0.12 (对) / -0.15 (错) |
| R6. 星图节点亮 | 熟练度高 → 节点变大/亮 | 实时刷 | knowledge_node 表 |
| R7. 进入下一题 | 继续 | SM2 排下一 | loop |

### A.5 第 4 时期 · 冲刺提升期

| 步骤 | 用户行为 | 系统响应 | 数据 |
|---|---|---|---|
| S1. 进入预测卷 | 选"高考冲刺" Tab | AI 按星图弱项组卷 | predicted_papers 表 |
| S2. 看命题依据 | 每题显示 "命题依据: 2024 北京卷第 8 题 / 考点: 椭圆焦点 / 命中: 难度+情境" | meta 字段 | — |
| S3. 限时完成 (25 min) | 倒计时 | submit → AI 批改 | paper_sessions |
| S4. 查看报告 | 错题自动入 SM2 队列 (同 D4) | 知识点星图刷新 | — |
| S5. 回到第 3 时期 | 安排下一轮复习 | close loop ✓ | — |

### A.6 模块间数据流关系

```
拍照 → vision_jobs (识别结果)
   ↓
错题 → wrong_questions (学科+KP+mastery_score)
   ↓
SM2 → srs_review_log (质量+EF+下次间隔)
   ↓
熟练度 → knowledge_node (星图节点亮度/大小)
   ↓
弱项 → predicted_papers (AI 组卷依据)
   ↓
答错 → 回到 wrong_questions (loop 闭合)
```

### B.2 全局规范

**底部 Tab 结构** (主导航, 学生 v1) — Tab 名以 §F.15 为准:
- `首页` (practice-hub-v2) · `错题` (wrong-book) · `拍照` (pwa-photo · **中央凸起**) · `复习` (learning-path / review-session) · `我的` (settings)

**色彩体系**: 见 §A.3 + 9 学科色 (顺序: 语文橙 / 数学红 / 英语紫 / 物理蓝 / 化学绿 / 生物青 / 历史琥珀 / 地理青柠 / 政治粉)

**字体层级**: DM Sans (拉丁) + Noto Sans SC (中文) + Noto Serif SC (作文/引言) + JetBrains Mono (数字)

**圆角与阴影**: pill (9999px) · md (14px · 卡片) · sm (8px · chip) · shadow-1 (静态) · shadow-3 (悬浮) · shadow-primary (CTA)

**核心交互**:
- 150-300ms ease-out cubic-bezier(.22,1,.36,1)
- focus-visible 红色 outline (3px offset)
- prefers-reduced-motion 必须支持
- 数据加载: skeleton (列表) / spinner-brand (单点) / progress-bar (明确进度)

### B.4 三条关键流程跳转图 (v2 同步)

#### B.4.1 初始化流程 (新用户)

```
landing → register (1 步, 仅账号凭证)
        手机号+验证码 (主) | 微信 OAuth (次) | 邮箱+密码 (兜底)
        ↓
       onboarding (5 步, 支持"稍后再选 →" 跳默认)
        Step 1 昵称+头像
        Step 2 年级 (写入学段 → 自动判定 中考区/高考区)
        Step 3 省份 (高考时必填, 31 省) → 按 §F.8 映射表判定 3+3 / 3+1+2
        Step 4 选科 (中考 9 科全开 / 高考 3+3 或 3+1+2 选 6 科)
        Step 5 首题引导 (拍照 → 入错题本 → SM2 排名 #1)
        ↓
       practice-hub-v2 (主屏, 8 件套)
```

回退: register 可"切换方式" (手机号↔微信↔邮箱); onboarding 每步可"跳过" (走默认: 高中 3+3 物化生).

#### B.4.2 拍照搜题流程 (无变化, 仍 A.3)

```
pwa-photo (3 stage) → vision-result → wrong-book (新错题排第一) → practice-hub-v2
```

#### B.4.3 复习流程 (★ 新版, 引 §F.9 相似题策略)

```
notifications → 收到 "今日 1 组到时"
  ↓
review-session (全屏卡片流, ★ 新页)
  Group 1 / 3,  卡片 1 / 4
  ├─ 错题 1 (主题)
  ├─ 相似题 1 (同考点同难度, AI 生成)
  ├─ 相似题 2
  └─ 相似题 3
  每张卡片: 显示题干 → 答题 → 翻面看答案 → 评分 (0-5)
  4 张完成后:
  ├─ ≥2 对 → 该组 mastery 额外 +0.05
  └─ 全错 → 该轮 q 封顶 2 (熟练度不升)
  更新 srs_review_log → EF 重算 → 下一组
  ↓
mastery_score / notifications (复习完成)
  ↓
knowledge-star (熟练度反馈) — 节点亮/暗变化
  ↓
回到 practice-hub-v2 (新任务入队列)
```

**关键提示 (Stage 2 红线)**: 0-5 评分要做成"一眼可操作"的横向大按钮组, 不能用 select. (Stage 2 设计师必须做横排滑块 / pill 段控件)
        ↓
learning-path (周排期) 或直接进入错题本
        ↓
SM2 调度按间隔推题 (薄弱 → 1d / 良好 → 6d)
        ↓
每题 4-步: 显示题干 → 答题 → 评分 (0-5) → 反馈
        ↓
EF' = EF + (0.1-(5-q)*(0.08+(5-q)*0.02))
        ↓
        ├─ q ≥ 3: interval = round(interval × EF')  → 熟练度 ↑ → 星图节点 ↑
        └─ q < 3:  interval = 1d                    → 熟练度 ↓ → 星图节点 ↓
        ↓
mastery (星图) / notifications (复习完成提醒)
        ↓
回到 practice-hub-v2 (新任务入队列)
```

回退: 任何时刻可"跳过本题" (不算复习, 不更新 EF) / "稍后提醒"
