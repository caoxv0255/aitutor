## 一、2008-2025 中国高考改革时间线 (已知)

```
2008-2013   旧模式
  - 大部分省份自主命题 (语数英 9 科或部分)
  - 全国卷I: 河南 河北 山西 广西
  - 全国卷II: 贵州 云南 西藏 甘肃 内蒙古 青海
  - 海南: 自主命题 (单独)

  2014-09  第一批: 上海 + 浙江 (3+3 选科)

  2017-秋   北京 天津 山东 海南 加入 (2020 实施)
  2018-春   河南 江苏 广东 安徽 湖南 湖北 河北 辽宁 福建 等 8 省 (2021 实施)
  2019-春   重庆 广西 江西等 (2021 实施)

  北京 天津 山东 海南: 首次新高考
```

## 五、PDF 分离方案评估

### 当前状态

```
database/高考真题/北京高考/2. 北京高考数学2008-2025/
  2008年北京高考数学试卷（文科）（解析版）.doc   ← 用于 RAG 提取
  2008年北京高考数学试卷（文科）（解析版）.pdf   ← 用于显示/下载
  2008年北京高考数学试卷（文科）（原卷版）.pdf
  ...
```

**doc + pdf 同目录, 同名配对, 命名规则一致 (原卷版/解析版)**。

### 方案对比

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **A. 现状不变** (同目录) | 用户视觉上 doc/pdf 一组 | 0 区别, 已经是这样 | ⭐⭐⭐⭐ |
| **B. 拆 raw/ + display/** | 清晰分层 | 多一层目录, 路径变长, 前端引用要改 | ⭐⭐ |
| **C. 拆 doc/ + pdf/ 同名平铺** | 同名平铺, 前端按扩展名区分 | 路径长, 跟前端约定耦合 | ⭐ |
| **D. docx 转换时输出 PDF (libreoffice)** | 一份源, 多份输出 | LO 转换 PDF 慢, 大文件 | ⭐⭐ |

### 推荐方案: A (现状不变) + 命名约定

**理由**:
1. doc 是 RAG 提取源 (内部), pdf 是用户显示 (外部)
2. 用户在文件管理器/前端都希望 "这一年的试卷" 一起出现
3. 扩展名天然区分, 命名规则统一 (`原卷版` / `解析版`)
4. 前端代码: `if (ext === '.pdf') render_pdf(); else if (ext === '.docx') download_docx();`
5. 不需要新目录结构, 不需要改 git/path, 不需要改前端

**可改进**:
- 在每个 docx 目录加一个 `README.md` 说明: 哪几个是 doc (RAG 用), 哪几个是 pdf (显示用)
- 或者在 manifest.json 加 file_kind 字段: 'docx' (rag source) / 'pdf' (display)

### PDF 真正需要解决的问题

```
1. 大量 doc 没配对 pdf (北京 36 doc vs 36 pdf, 基本对得上)
2. 一些 pdf 没配对 doc (解析版可能用户用 PDF 看)
3. 部分老试卷 (2010 之前) 只有 doc 没 PDF (扫描老试卷情况)
4. 2024-2025 新高考 教育部发布 pdf, doc 需要转
```
