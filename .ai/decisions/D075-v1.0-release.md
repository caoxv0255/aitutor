## 3. 部署清单

### 3.1 生产环境要求

| 项 | 要求 | 现状 |
|---|---|---|
| Node.js | 18+ (推荐 22) | ✅ Node 22.22.3 |
| PostgreSQL | 15+ with pgvector + AGE | ✅ aitutor-db-1 (healthy) |
| Redis | 7+ | ✅ aitutor-redis-1 (healthy) |
| 内存 | 2GB min, 4GB 推荐 | ✅ |
| 磁盘 | 20GB min (数据库 + OCR 缓存) | ✅ |
| 网络 | HTTPS (Nginx 反向代理) | ✅ aitutor.uibe.online |

### 3.2 必需环境变量

```bash
# 必需
DATABASE_URL=postgresql://aitutor:password@db:5432/aitutor_db
JWT_SECRET=<openssl rand -hex 32>
PORT=3002
NODE_ENV=production

# 强烈推荐
DASHSCOPE_API_KEY=<阿里云百炼>     # ⚠️ 当前测试 key 失效, 需新 key
DASHSCOPE_BASE_URL=<阿里云兼容模式端点>
OLLAMA_URL=http://host.docker.internal:11434  # bge-m3
ALLOWED_ORIGINS=https://aitutor.uibe.online
```

### 3.3 部署命令（Docker Compose 方式）

```bash
# 一键部署（推荐）
sudo bash deploy/setup-prod.sh

# 或手动
docker compose -f docker-compose.prod.yml up -d

# 健康检查
curl http://localhost:3002/api/health
# 期望: {"success":true,"data":{"dbReady":true,...}}

# 服务注册
docker compose -f docker-compose.prod.yml ps
```

### 3.4 数据库初始化

启动时 `db.js` 自动：
1. `CREATE EXTENSION IF NOT EXISTS vector`
2. 创建 30+ 张表（IF NOT EXISTS）
3. 应用 8 个迁移（005-012 + 011 + 013-016）
4. 启动 task_worker

**首次部署额外步骤**:
```bash
# 1. 灌入 19,713 道题（容器内）
docker exec -w /app aitutor-app-1 sh -c "
  DATABASE_URL='postgresql://aitutor:aitutor_password@db:5432/aitutor_db' \
  timeout 300 node scripts/ingest-exam-questions.mjs
"

# 2. 同步 57 papers（容器内）
docker cp scripts/sync-papers-from-questions.sql aitutor-db-1:/tmp/
docker exec aitutor-db-1 psql -U aitutor -d aitutor_db -f /tmp/sync-papers-from-questions.sql

# 3. （可选）配置 DASHSCOPE_API_KEY 后测试 OCR
```
