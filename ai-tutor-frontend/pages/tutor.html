好的，我们一步一步来解这道题。这是一道典型的待定系数法求解二次函数解析式的题目。

1 第一步：根据已知条件列方程

因为函数 f(x) = ax² + bx + c 经过三个点，我们可以将每个点的坐标代入函数式：

  • 经过点 (1, 0)：a·1² + b·1 + c = 0，即 a + b + c = 0 ……①
  • 经过点 (3, 0)：a·3² + b·3 + c = 0，即 9a + 3b + c = 0 ……②
  • 经过点 (0, 3)：a·0² + b·0 + c = 3，即 c = 3 ……③

2 第二步：解方程组

将③代入①和②，得到：

  • a + b = -3 ……①′
  • 9a + 3b = -3，化简为 3a + b = -1 ……②′

用②′ - ①′消元：

(3a + b) - (a + b) = -1 - (-3)，解得 a = 1

代回①′：1 + b = -3，解得 b = -4

3 第三步：验证答案

所以函数解析式为：

f(x) = x² − 4x + 3
验证：f(1)=1−4+3=0 ✓   f(3)=9−12+3=0 ✓   f(0)=3 ✓

! 小提示： 因为二次函数与x轴交于(1,0)和(3,0)，也可以直接使用交点式 f(x) = a(x−1)(x−3)，再代入(0,3)快速求出 a = 1，这样计算更快捷。
