已知二次函数 y = ax2 + bx + c (a≠0) 的图像如图所示，下列结论正确的是（    ）

正确答案 C 正确率 68%
  1. 1 由图像开口方向向下，可判断 a < 0；
  2. 2 对称轴 x = −b/(2a) > 0，结合 a < 0，可得 b > 0；
  3. 3 图像与 y 轴交点在正半轴，故 c > 0；
  4. 4 因此 abc < 0，A 错误；
  5. 5 图像与 x 轴有两个交点，故 b2 − 4ac > 0，B 错误；
  6. 6 由图可知对称轴在直线 x = 1 的右侧，即 −b/(2a) > 1；结合 a < 0，两边同乘 2a（负数，不等号反向）得 −b < 2a，即 2a + b > 0，C 正确；
  7. 7 当 x = −1 时，图像上对应点在 x 轴上方，故 a − b + c > 0，D 错误；
  8. ✓ 综上，A、B、D 均错误，正确选项为 C。
核心推导
a < 0,  b > 0,  c > 0  ⇒  abc < 0  ✗
Δ = b2 − 4ac > 0  （两个交点）  ✗
−b/(2a) > 1  ⇒  −b < 2a  ⇒  2a + b > 0  ✓
f(−1) = a − b + c > 0  ✗
