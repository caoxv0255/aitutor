## 实施方案

### Phase 1: 修复 fix-placeholder-paths.js 的年份匹配Bug

**文件**: `scripts/fix-placeholder-paths.js`

**问题**: `findCorrectFileInProvinceDir` 函数使用 `readdirSync(provinceDir, { recursive: true })` 返回完整路径（如 `6. 安徽高考生物2008-2025\2012年高考生物试卷（安徽）（空白卷）.pdf`），过滤时 `f.includes(yearStr)` 会匹配目录名中的"2008"，导致返回错误年份的文件。

**修复**: 在过滤前提取文件名，只检查文件名中的年份：
```javascript
// 修改前 (第92-98行):
const candidates = allFiles.filter(f => {
  return f.includes(yearStr) && ...

// 修改后:
const candidates = allFiles.filter(f => {
  const fName = f.split(/[/\\]/).pop() || '';
  return fName.includes(yearStr) && ...
```

同样修复第123-127行的 `analysisCandidates` 过滤。

### Phase 2: 创建全量占位文件修复脚本

**新文件**: `scripts/fix-all-placeholder-paths.js`

扩展占位修复到所有paper_type（不只是independent），实现全国卷文件共享策略：

1. **检测所有占位文件**: 查询所有 `paper_file_path` 指向其他省份的记录
2. **三层修复策略**:
   - **Layer 1 - 本省文件**: 在本省目录中搜索正确文件（年份+学科+文理科匹配）
   - **Layer 2 - 全国卷共享**: 对于同paper_type+同年份+同学科的记录，如果某省份有本省文件，其他省份共享该文件路径
   - **Layer 3 - 保留占位**: 无法修复的记录保留原路径，但在报告中列出
3. **math_type处理**: 按用户要求保持NULL（置空待修复）
4. **特殊处理**:
   - 2025年数学: 很多省份有"新课标全国I/II卷"文件，修复占位指向本省文件
   - 北京政治2008: 目录中是生物文件，标记为异常

**修复逻辑**:
```
对于每条占位记录:
  1. 在本省目录搜索 → 找到则修复
  2. 查找同paper_type+year+subject的其他省份本省文件 → 找到则共享
  3. 都找不到 → 保留占位，记录到报告
```

### Phase 3: PDF文件命名标准化

**新文件**: `scripts/standardize-file-names.js`

对所有PDF/DOC/DOCX文件实施统一命名规范：

**标准命名格式**:
```
{年份}年{省份}高考{学科}试卷（{卷型}）（{版本}）.{ext}
```

**示例**:
- `2008年北京高考数学试卷（文科）（原卷版）.pdf`
- `2010年全国I卷高考物理试卷（空白卷）.pdf`
- `2025年新高考I卷高考数学试卷（原卷版）.pdf`

**命名规则**:
1. **年份**: 4位数字 + "年"
2. **省份/卷型**: 
   - 自主命题: 省份名（如"北京"、"上海"）
   - 全国卷: "全国I卷"、"全国II卷"、"全国III卷"、"全国甲卷"、"全国乙卷"
   - 新高考: "新高考I卷"、"新高考II卷"
3. **学科**: 语文/数学/英语/物理/化学/生物/政治/历史/地理
4. **数学分科**: 文科数学加"（文科）"，理科数学加"（理科）"，不分文理省略
5. **版本**: 原卷版/空白卷/解析版/含解析版/答案版

**处理步骤**:
1. 扫描所有文件，解析当前文件名提取关键信息
2. 生成标准化文件名
3. 检查目标文件名是否已存在（避免冲突）
4. 重命名文件（保留原文件名映射记录）
5. 更新数据库中的 `paper_file_path`

**清理规则**:
- 删除临时文件: `.cache.*`, `~$*`
- 去重: 同一年份+学科+版本的重复文件保留最新/最完整的
- 修复北京政治2008目录中的生物文件错误

## 假设与决策

1. **全国卷共享策略**: 同一paper_type+年份+学科的省份共享同一文件路径。例如，2010年使用national_i的hebei和henan共享同一个全国I卷物理文件。
2. **math_type保持NULL**: 88条NULL记录暂不处理，等找到正确的文/理科数学文件后再设置。
3. **文件重命名**: 使用 `fs.renameSync` 进行原子重命名，保留原文件名到新文件名的映射。
4. **不删除文件**: 除非是明确的临时文件（`.cache.*`, `~$*`），否则不删除任何文件。
5. **UIBE Git服务器**: 从本机不可达，不作为文件获取来源。
6. **数据库路径格式**: 使用正斜杠 `/` 作为路径分隔符（兼容性最好）。

5. **Phase 5验证**: 检查7条试卷的question_count是否已填充
6. **Phase 6验证**: 检查报告内容完整性和准确性
