## 参考答案

解：由正弦定理，a/sinA = b/sinB，得2/sinA = √6/sin60°，sinA = (2×√3/2)/√6 = √3/√6 = √2/2，所以A=45°或135°，但a<b，所以A<B，故A=45°。C=180°-45°-60°=75°。由正弦定理，c/sinC = a/sinA，c = a sinC/sinA = 2×sin75°/(√2/2) = 4×sin75°/√2，sin75°=sin(45°+30°)= (√6+√2)/4，所以c=4×(√6+√2)/(4√2)= (√6+√2)/√2 = √3+1。

## 解析

本题考查正弦定理的应用。解题思路：利用正弦定理求角A，注意大边对大角，确定A的唯一性，再求角C和边c。关键知识点：正弦定理、三角形内角和、两角和的正弦公式。评分标准：正确使用正弦定理得2分，求出A得2分，求出C得2分，求出c得2分，结果正确得2分。
