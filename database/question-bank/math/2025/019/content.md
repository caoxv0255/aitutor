# 第19题

**题型**: 解答题

**难度**: ★★★★☆

**分值**: 15分

**知识点**: 椭圆方程、直线与椭圆、面积比

---

## 题目内容

已知椭圆 E: x^2/a^2 + y^2/b^2 = 1 的离心率为 √2/2，椭圆上的点到两焦点距离之和为 4.
（1）求椭圆方程；
（2）设 O 为原点，M(x0, y0) (x0≠0) 为椭圆上一点，直线 x0x/2 + y0y/2 - 2 = 0 与直线 y=2, y=-2 交于 A, B. △OAM 与 △OBM 的面积为 S1, S2，比较 S1/S2 与 |OA|/|OB| 的大小.

## 小题

### 19(1)

求椭圆方程

**答案**: x^2/4 + y^2/2 = 1

### 19(2)

比较 S1/S2 与 |OA|/|OB| 的大小

**答案**: S1/S2 = |OA|/|OB|

---

## 参考答案

（1）x^2/4 + y^2/2 = 1；（2）S1/S2 = |OA|/|OB|

## 解析

（1）由 2a=4 得 a=2，e=c/a=√2/2 得 c=√2，b^2=a^2-c^2=2，椭圆方程为 x^2/4+y^2/2=1；（2）联立直线与椭圆得 M 为切点，计算 A、B 坐标，利用相似或向量夹角得 S1/S2 = |OA|/|OB|
