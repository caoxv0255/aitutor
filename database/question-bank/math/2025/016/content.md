**题型**: 解答题

## 题目内容

在 △ABC 中，cos A = -1/3, a = 4√2, sin C = √2/3.
（1）求 c；
（2）在以下三个条件中选择一个作为已知，使得 △ABC 存在，求 BC 的高.
① a=6；② b sin C = 10√2/3；③ △ABC 面积为 10√2.

## 小题

### 16(1)

求 c

**答案**: 6

### 16(2)

在以下三个条件中选择一个作为已知，使得 △ABC 存在，求 BC 的高.
① a=6；② b sin C = 10√2/3；③ △ABC 面积为 10√2.

**答案**: 选②：高为 10√2/3；选③：高为 20√2/9

---

## 参考答案

（1）c=6；（2）选②：高为 10√2/3；选③：高为 20√2/9

## 解析

（1）由 sin A = 2√2/3，正弦定理得 c = a sin C / sin A = 6；（2）选①得 a=c=6，但 cos A<0 得 A 为钝角，C 也为钝角，矛盾；选②由正弦定理得 sin B = 5√2/9，高 AD = c sin B = 10√2/3；选③由面积得 b=5，余弦定理得 a=√(b^2+c^2-2bc cos A)=√(25+36-2*5*6*(-1/3))=√(61+20)=9，高 h=2S/a=20√2/9
