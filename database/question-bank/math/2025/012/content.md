# 第12题

**题型**: 填空题

**难度**: ★★☆☆☆

**分值**: 5分

**知识点**: 二项式定理、赋值法

---

## 题目内容

已知 (1-2x)^4 = a_0 - 2a_1 x + 4a_2 x^2 - 8a_3 x^3 + 16a_4 x^4，则 a_0 = ________；a_1 + a_2 + a_3 + a_4 = ________

---

## 参考答案

1; 15

## 解析

令 x=0 得 a_0=1；令 x=1/2 得 0 = a_0 - a_1 + a_2 - a_3 + a_4，所以 a_1+a_2+a_3+a_4 = a_0 = 1？实际上，令 t=2x，则 (1-t)^4 = a_0 - a_1 t + a_2 t^2 - a_3 t^3 + a_4 t^4，令 t=1 得 0 = a_0 - a_1 + a_2 - a_3 + a_4，所以 a_1+a_2+a_3+a_4 = a_0 = 1？但答案给出 15，需重新计算：令 x=1 得 (1-2)^4 = 1 = a_0 - 2a_1 + 4a_2 - 8a_3 + 16a_4，又 a_0=1，所以 -2a_1+4a_2-8a_3+16a_4=0，即 -a_1+2a_2-4a_3+8a_4=0，与 a_1+a_2+a_3+a_4 关系？实际上，由二项式展开，a_0=1, a_1=8, a_2=24, a_3=32, a_4=16，所以 a_1+a_2+a_3+a_4=80？但答案 15 可能指 a_1+a_2+a_3+a_4=15？检查：令 x=1/2 得 0 = a_0 - a_1 + a_2 - a_3 + a_4，所以 a_1+a_2+a_3+a_4 = a_0 + 2(a_2+a_4)？不，由 0=1 - a_1 + a_2 - a_3 + a_4 得 a_1+a_2+a_3+a_4 = 1 + 2(a_2+a_4)？实际上，a_1+a_2+a_3+a_4 = (a_1 - a_2 + a_3 - a_4) + 2(a_2+a_4)？更简单：令 x=-1 得 (1+2)^4=81 = a_0 + 2a_1 + 4a_2 + 8a_3 + 16a_4，与 x=1 的式子相加得 82 = 2a_0 + 8a_2 + 32a_4，所以 a_2+4a_4=10，又 a_0=1，由 x=1/2 得 a_1 - a_2 + a_3 - a_4 = 1，由 x=-1/2 得 a_1 + a_2 + a_3 + a_4 = ？实际上，令 x=1/2 得 0 = a_0 - a_1 + a_2 - a_3 + a_4，所以 a_1 - a_2 + a_3 - a_4 = 1；令 x=-1/2 得 (1+1)^4=16 = a_0 + a_1 + a_2 + a_3 + a_4，所以 a_1+a_2+a_3+a_4 = 15。故答案为 1 和 15
