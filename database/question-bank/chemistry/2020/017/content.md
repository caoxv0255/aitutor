## 解析

【答案】
（1）第三周期第ⅡA族
（2）Mg(OH)2 + 2HCl = MgCl2 + 2H2O
（3）Mg(OH)2的碱性比NaOH弱，比Al(OH)3强
（4）Mg + 2H2O = Mg(OH)2 + H2↑
【解析】
（1）X为Mg，原子序数12，位于第三周期第ⅡA族。
（2）Mg(OH)2与盐酸反应生成MgCl2和H2O，化学方程式为Mg(OH)2 + 2HCl = MgCl2 + 2H2O。
（3）金属性：Na>Mg>Al，所以碱性：NaOH>Mg(OH)2>Al(OH)3。
（4）Mg与热水反应生成Mg(OH)2和H2，化学方程式为Mg + 2H2O = Mg(OH)2 + H2↑。
