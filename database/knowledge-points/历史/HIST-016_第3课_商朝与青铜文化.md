# 第3课 商朝与青铜文化

> 🟡 高考频率: **medium** | 难度: ⭐⭐ | 模块: 通用

## 核心内容

商朝历史是信史：文献、甲骨卜辞、考古发现构成研究上朝历史的多重史料；司母戊鼎；甲骨文；商

朝青铜器：功能上以礼器为主，青铜器反映器主等级和政治地位，青铜器反映商人的信仰和思想状况。

内外服制：内服是商王直接管辖的王畿之地，外服是商王通过方国首领间接管辖的畿外之地。
