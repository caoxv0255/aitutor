## 核心内容

1、概念：进位制是一种记数方式，用有限的数字在不同的位置表示不同的数值。可使用数字符号的个数

称为基数，基数为n，即可称n进位制，简称n进制。现在最常用的是十进制，通常使用10个阿拉伯数字

0-9进行记数。对于任何一个数，我们可以用不同的进位制来表示。比如：十进数57，可以用二进制表示

为111001，也可以用八进制表示为71、用十六进制表示为39，它们所代表的数值都是一样的。

一般地，若k是一个大于一的整数，那么以k为基数的k进制可以表示为：

n n1 1 0(k) n n1 1 0
