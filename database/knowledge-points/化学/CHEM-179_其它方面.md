# 其它方面

> 🟡 高考频率: **medium** | 难度: ⭐⭐⭐⭐⭐ | 模块: 通用

## 核心内容

(1)净水剂的选择:如Al ,FeCl 等均可作净水剂,应从水解的角度解释。

(2)化肥的使用时应考虑水解。如草木灰不能与铵态氮肥混合使用。

(3)小苏打片可治疗胃酸过多。

(4)纯碱液可洗涤油污。

(5)磨口试剂瓶不能盛放NaSiO,NaCO 等试剂.

2 3 2 3

凡此种种,不一而举。学习中要具体情况具体分析,灵活应用之。
