# 化合价

> 🟡 高考频率: **medium** | 难度: ⭐⭐ | 模块: 通用

## 核心内容

化合价是指一种元素一定数目的原子跟其他元素一定数目的原子化合的性质。

①在离子化合物中，失去电子的为正价，失去n个电子即为正n价；得到电子为负价，得到n个电子

②在共价化合物中，元素化合价的数值就是这种元素的一个原子跟其他元素的原子形成的共用电子对

的数目、正负则由共用电子对的偏移来决定，电子对偏向哪种原子，哪种原子就显负价；偏离哪种原子、

哪种原子就显正价。

③单质分子中元素的化合价为零。
