# 加热蒸发和浓缩盐溶液时,对最后残留物的判断应考虑盐类的水解

> 🟡 高考频率: **medium** | 难度: ⭐⭐⭐⭐⭐ | 模块: 反应原理

## 核心内容

(1)加热浓缩不水解的盐溶液时一般得原物质.

(2)加热浓缩NaCO 型的盐溶液一般得原物质.

(3)加热浓缩FeCl 型的盐溶液.最后得到FeCl 和Fe(OH) 的混合物,灼烧得FeO 。

3 3 3 2 3

(4)加热蒸干(NH)CO 或NHHCO 型的盐溶液时,得不到固体.

4 2 3 4 3

(5)加热蒸干Ca(HCO) 型的盐溶液时,最后得相应的正盐.

(6)加热Mg(HCO)、MgCO 溶液最后得到Mg(OH) 固体.
