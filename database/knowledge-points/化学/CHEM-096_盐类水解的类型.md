# 盐类水解的类型

> 🟡 高考频率: **medium** | 难度: ⭐⭐⭐⭐ | 模块: 反应原理

## 核心内容

（1）单向水解：强酸和弱碱生成的盐，溶液呈酸性；强碱和弱酸生成的盐，溶液显碱性。如NHCl溶

NH+ + HO NH·HO + H+

（2）互相促进水解：弱酸和弱碱生成的盐溶于水，电离产生弱酸的阴离子和弱碱的阳离子，二者分

别结合水电离产生的H+和OH-发生水解，而水溶液的离子积不变，因此促进水的电离使反应进行的程度较

大。溶液的酸碱性取决于生成的弱电解质的相对强弱。如CHCOONH 溶于水：

CH3COO-+ NH+ CHCOOH + NH·HO

4 3 3 2

（3）互相抑制水解：能电离产生两种以上的弱酸阴离子或弱碱阳离子的盐溶于水，弱酸的阴离子或弱

碱的阳离子均发生水解，但是互相抑制，所以这一类的水解程度较小。如(NH)Fe(SO) 溶于水：

NH+ + HO NH·HO + H+
