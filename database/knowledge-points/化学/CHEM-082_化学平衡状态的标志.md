# 化学平衡状态的标志

> 🔴 高考频率: **high** | 难度: ⭐⭐⭐ | 模块: 反应原理

## 核心内容

化学平衡状态的判断（以mA+nB xC+yD为例），可从以下几方面分析：

①v(B )=v(B )

②v(C ):v(D )=x : y

③c(C)、C%、n(C)%等不变

④若A、B、C、D为气体，且m+n≠x+y，压强恒定

⑤体系颜色不变

⑥单位时间内某物质内化学键的断裂量等于形成量

⑦体系平均式量恒定（m+n ≠ x+y）等
