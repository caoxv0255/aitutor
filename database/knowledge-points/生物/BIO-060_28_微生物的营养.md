# 28 微生物的营养

> 🟡 高考频率: **medium** | 难度: ⭐⭐⭐ | 模块: 通用

## 核心内容

无机碳源 CO 、NaHCO 等

碳源 提供碳素营养

有机碳源 糖、脂、石油等

无机氮源 N 、硝酸盐、铵盐等

氮源 提供氮素营养

有机氮源 尿素、牛肉膏、蛋白胨等

微生物生长不可缺少的微量有机物

（包括维生素、氨基酸、碱基等）

物 目的要明确 根据培养种类、培养目的选择原材料

营养要协调 注意营养物质的浓度和比例

（三要原则） C/N=4：有利于繁殖；

碳氮比最重要

C/N=3：有利于产谷氨酸

细 菌：pH=6.5—7.5

pH要适宜 放线菌：pH=7.5—8.5

真 菌：pH=5.0—6.0

种类 特点 功能

固体培养基 分离、鉴定

物理 加凝固剂

半固体培养基 观察、保藏
