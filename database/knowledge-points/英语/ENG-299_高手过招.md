# 高手过招

> 🟡 高考频率: **medium** | 难度: ⭐⭐⭐⭐ | 模块: 练习与应用

## 核心内容

单句改错 （原创）

①Sheisveryparticularforherclothes.

②Thesedocumentsareofparticularlyimportance.

答案: ①for→ about/over ② particularly → particular

PageNo.527

7.badlyoff

穷的；处境差的；缺少的

Iamquitebadlyoffrecently.

最近我经济上很拮据。

bebadlyoffforsth. 需要（某物）；（某物）供应不足

worseoff 境况更差；更穷困

welloff 富裕；处境好

（比较级：betteroff境况更佳）

Hishealthisworseoffthanbefore.

他的身体状况比以前更糟糕了。

Capitalismcanmakeyouwelloff.

资本主义可以让你变得富裕。
