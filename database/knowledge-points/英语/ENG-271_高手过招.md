# 高手过招

> 🟡 高考频率: **medium** | 难度: ⭐⭐⭐⭐ | 模块: 练习与应用

## 核心内容

① Only then how much damage had been caused.

A.sherealized B.shehadrealized

C.hadsherealized D.didsherealize

（2010·01·安徽合肥高三检测）

Only B.Just C.Still D.Yet

①解析：选D。“only+状语”放在句首时，主句部分要用部分倒装，再根据时间then判断，主句应用一般

过去时，所以选D。

②解析：选A。四个选项中，只有“only+状语”放在句首时，主句才用部分倒装。
