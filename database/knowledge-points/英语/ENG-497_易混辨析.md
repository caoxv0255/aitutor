# 易混辨析

> 🟡 高考频率: **medium** | 难度: ⭐⭐⭐⭐⭐ | 模块: 词汇与辨析

## 核心内容

drag/draw/pull

drag 表示费力，缓慢而艰难地“拉、拖”较重的物体。

draw 表示从容地“拉、拖”。

pull 表示突然、急速地“拉”，方式不限。

Wedraggedthefallentreefromtheroad.

我们把倒在路上的树拖到一边。

Drawyourchairuptothetable.

把你的椅子拉到桌子旁边来。

Fivemonkeyspulltheelephant.

五只猴子在拉大象。
